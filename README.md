# YT-Chat

## 実行方法

1.  ターミナル（コマンドプロンプト）を開き、以下のコマンドを実行してサーバーを起動します。

    ```bash
    node server.js
    ```

    `Server is running on http://localhost:3001` と表示されれば成功です。

2.  お使いのウェブブラウザを開き、アドレスバーに以下のURLを入力してアクセスします。

    ```
    http://localhost:3001
    ```

## 使い方

1.  ブラウザに表示されたサイトで、YouTubeライブ配信のURLを入力します。
2.  「Get Chat」ボタンをクリックすると、チャットの表示が開始されます。

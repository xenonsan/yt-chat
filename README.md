# YouTubeチャットビューア (シンプル版)

これまでの問題を解決するため、依存関係（`npm install`）が一切不要な、非常にシンプルな構成に作り直しました。

## 実行方法

1.  ターミナル（コマンドプロンプト）を開き、以下のコマンドを実行してサーバーを起動します。

    ```bash
    node server.js
    ```

    `Server is running on http://localhost:3001` と表示されれば成功です。

2.  お使いのウェブブラウザを開き、アドレスバーに以下のURLを入力してアクセスします。

    ```
    http://localhost:3001
    ```

これだけでアプリケーションが使用できます。

## 使い方

1.  ブラウザに表示されたサイトで、YouTubeライブ配信のURLを入力します。
2.  「Get Chat」ボタンをクリックすると、チャットの表示が開始されます。

### 以前のファイルについて

この新しいバージョンは `server.js` と `index.html` の2つのファイルのみで動作します。

古い `client` や `server` ディレクトリ、`package.json` ファイルが残っていても、この新しいバージョンの動作には影響ありませんので、無視していただいて大丈夫です。
